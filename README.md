# Awesome DSH Plugin [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（`dsh`）插件精选列表
>
> A curated list of plugins for DeepSeek Harness.

## 插件 / Plugins

- [dsh-vision-toolkit](https://github.com/Anionex/dsh-vision-toolkit) — 让纯文本模型更好地做视觉任务：带意图的图片问答、长截图 OCR、UI 还原等。<br>Vision tasks for text-only models: intent-aware image Q&A, long-screenshot OCR, UI reproduction, and more.
- [dsh-tianshu-tui](https://github.com/huiliyi37/dsh-tianshu-tui) — DeepSeek Harness 的终端 UI（TUI）。<br>A terminal UI (TUI) for DeepSeek Harness.
- [dsh-at-file](https://github.com/omdsh-dev/dsh-at-file) — Codex 风格的 `@file` 文件引用，输入框里直接搜索并引用工作区文件。<br>Codex-style `@file` mentions: search and reference workspace files right from the input box.
- [dsh-open-in-vscode](https://github.com/omdsh-dev/dsh-open-in-vscode) — 一键在 VS Code 中打开 DSH 工作区目录。<br>Open DSH workspace directories in VS Code with one click.
- [dsh-notification](https://github.com/omdsh-dev/dsh-notification) — 桌面通知：回合完成等事件的系统级提醒。<br>Desktop notifications for turn completions and other events.
- [dsh-custom-tool](https://github.com/omdsh-dev/dsh-custom-tool) — 创建和管理沙箱化的自定义 JavaScript 工具。<br>Create and manage sandboxed custom JavaScript tools.
- [dsh_workflow](https://github.com/icetomoyo/dsh_workflow) — 把 UltraCode 式多 Agent 调度带给 DSH：可生成、可保存、可复用的工作流。<br>UltraCode-style multi-agent orchestration for DSH: generatable, savable, reusable workflows.
- [dsh-turn-rewind](https://github.com/Anionex/dsh-turn-rewind) — 对话回退：回滚会话与工作区到任意轮次。<br>Conversation rewind: roll back session and workspace to any turn.
- [dsh-visualize](https://github.com/Nagi-ovo/dsh-visualize) — 对话内生成式 UI：模型把交互式 HTML 卡片直接画进会话流。<br>In-conversation generative UI: the model renders interactive HTML cards directly into the chat stream.
- [dsh-share](https://github.com/hellodigua/dsh-share) — 一键分享你的 DSH 对话。<br>Share your DSH conversations with one click.

## 贡献 / Contributing

欢迎提 PR 收录你的插件：一行一条，格式 `- [名称](链接) — 中文描述<br>English description`。

也请为你的插件仓库添加 [`dsh-plugin`](https://github.com/topics/dsh-plugin) topic，方便大家发现。

PRs welcome — one line per plugin: `- [name](link) — 中文描述<br>English description`. Please also add the [`dsh-plugin`](https://github.com/topics/dsh-plugin) topic to your repo.
