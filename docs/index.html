安装Installing

# npm 包（推荐：预构建，一次成功）from npm (recommended: prebuilt, works first try)
dsh plugin --profile default add <npm-package>

# GitHub 源码（首次会要求构建授权，按提示配置 allowBuilds 后重试）from GitHub (first run asks for build approval — follow the allowBuilds hint, retry)
dsh plugin --profile default add github:<owner>/<repo>

⚠️ GitHub 来源的插件在安装时会于你的机器上执行构建脚本，请只安装可信来源，并尽量锁定 commit（github:owner/repo#sha）。⚠️ GitHub-sourced plugins run build scripts on your machine at install time. Only install sources you trust, and pin a commit (github:owner/repo#sha).
