安装

# npm 包（预构建）
dsh plugin --profile web add <npm-package>

# GitHub 源码（首次需按提示配置 allowBuilds 构建授权后重试）
dsh plugin --profile web add github:owner/repo

GitHub 来源的插件在安装时会在你的机器上执行构建脚本。请只安装可信来源，并尽量锁定 commit（github:owner/repo#sha）。
