DeepSeek Harness 插件

itr-del/dsh-feishu

分类 通知与集成 收录于 2026-08-14

DeepSeek Harness 的飞书/Lark 私聊桥接插件，支持 `dsh plugin add` 一键安装，配套完整调试文档。

安装

# GitHub 源码（首次需按提示配置 allowBuilds 构建授权后重试）

dsh plugin --profile web add github:itr-del/dsh-feishu

GitHub 来源的插件在安装时会在你的机器上执行构建脚本。请只安装可信来源，并尽量锁定 commit（github:owner/repo#sha）。
