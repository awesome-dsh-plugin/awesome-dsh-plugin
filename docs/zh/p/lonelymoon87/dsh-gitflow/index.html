lonelymoon87/dsh-gitflow

Star 数 ★ 1 分类 开发与运行时 收录于 2026-08-14

增加需要审批的 Git 状态、diff、日志、提交、分支和可选检查点工具。

安装

# GitHub 源码（首次需按提示配置 allowBuilds 构建授权后重试）

dsh plugin --profile web add github:lonelymoon87/dsh-gitflow

GitHub 来源的插件在安装时会在你的机器上执行构建脚本。请只安装可信来源，并尽量锁定 commit（github:owner/repo#sha）。
