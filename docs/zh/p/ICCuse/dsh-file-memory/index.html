ICCuse/dsh-file-memory

Star 数 ★ 0 分类 记忆 收录于 2026-08-14

文件型工作记忆：memorize/recall 把关键前提逐字保存在会话笔记文件，无损挺过上下文压缩。

安装

# GitHub 源码（首次需按提示配置 allowBuilds 构建授权后重试）

dsh plugin --profile web add github:ICCuse/dsh-file-memory

GitHub 来源的插件在安装时会在你的机器上执行构建脚本。请只安装可信来源，并尽量锁定 commit（github:owner/repo#sha）。
