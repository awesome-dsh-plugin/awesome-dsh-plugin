DeepSeek Harness 插件

radres/dsh-plugin-call-me

Star 数 ★ 1 分类 通知与集成 收录于 2026-08-14

通过 CallKit 打电话到你的手机：`call_me` 与 `text_me` 工具，并可在回合结束或等待审批时来电，语音回答转写后送回会话。

安装

# GitHub 源码（首次需按提示配置 allowBuilds 构建授权后重试）

dsh plugin --profile web add github:radres/dsh-plugin-call-me

GitHub 来源的插件在安装时会在你的机器上执行构建脚本。请只安装可信来源，并尽量锁定 commit（github:owner/repo#sha）。
