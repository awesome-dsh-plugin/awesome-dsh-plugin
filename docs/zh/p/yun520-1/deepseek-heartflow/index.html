README

心虫 HeartFlow 是 AGI 五层能力中的第 1 层——辨别者（Discriminator）。 它不生成、不推理、不记忆、不执行，只判别已有的东西对不对。 大模型能产生无限内容，但需要谁来判别？心虫是那个判别者。

本插件把心虫的 47 维纯规则判别引擎接入 DeepSeek Harness (dsh)，让模型的每一步输出在到达用户之前，先过一道辨别门禁。

核心价值：减少大模型产生的疑问和幻觉——过度自信、自相矛盾、逻辑谬误、情绪操控、非人化、仇恨言论，在说出口之前拦下。

✨ 功能

10 个工具

工具 说明
heartflow_check 完整 47 维判别。返回 gate.action（block/rewrite/verify/pass）+ 全部 findings 修正指引
heartflow_analyze 深度分析。全维度打分（discriminate）+ 交叉分析（crossAnalyze）+ 摘要（summarizeDiscrimination）
heartflow_verdict 快速裁决。只返回 action + 一句话原因 + 顶部 3 个 findings，token 友好
heartflow_dimensions 维度清单。列出全部判别维度 + 引擎版本
heartflow_pipeline 管道模式。完整 gate 生命周期：input(输入) / draft(草稿) / output(输出) 三阶段，返回 action + checked_by
heartflow_check_input 输入检查。用户消息进入 agent 前拦截提示注入/恶意指令/仇恨言论
heartflow_check_draft 草稿检查。模型回复前拦截过度自信/矛盾/情绪操控/非人化
heartflow_check_output 输出检查。最终输出前拦截编造数据/无来源声明/过度声称
heartflow_discriminate 全维度原始打分。每个维度的命中/得分 + 门禁判定
heartflow_evidence 带证据检查。gate(text, evidence) 提供证据做事实一致性/伪证据判别

双防线自动监督钩子

模型每次工具调用的参数都会被心虫自动判别（tools/pre-execute + tools/post-execute，dsh guard 标准注入点）：

前置防线 tools/pre-execute — 工具执行前判别参数：

  • block 级：返回 {kind:'deny'} 直接拒绝执行（危险内容/命令在运行前拦下，不浪费执行）

后置防线 tools/post-execute — 执行后判别：

  • block 级：返回 {kind:'block'} 硬拦截，注入判别结果让模型修正
  • rewrite/verify 级：注入提醒（additionalContexts），不硬拦

47 维判别能力（AGI 第 1 层）

本插件完整继承原始心虫全部能力——7 个 gate 入口（gate/check/pipeline/runPipeline/discriminate/checkInput/checkDraft/checkOutput）+ 48 个单维判别函数 + 3 个辅助（summarizeDiscrimination/crossAnalyze/entropyAnalysis），全部暴露为 dsh 工具。

安全设计

  • fail-closed：引擎加载失败时，heartflow_check 返回 block（引擎不可用），绝不静默放行
  • 零 LLM 依赖：纯规则引擎，无 API、无数据库、无网络——判别不花一分钱 token
  • 不写死路径：引擎来源只认环境变量 HEARTFLOW_ENGINE_PATH 和 npm 包

📦 安装

从 GitHub

dsh plugin add github:yun520-1/deepseek-heartflow

从 npm（推荐，免构建授权）

dsh plugin add @yun520-1/deepseek-heartflow
# 或全局安装
npm install -g @yun520-1/deepseek-heartflow

引擎依赖

插件需要心虫引擎（@yun520-1/heartflow，47 维判别核心）。加载顺序：

  1. 环境变量 HEARTFLOW_ENGINE_PATH 指向的本地副本
  2. npm 包 @yun520-1/heartflow
  3. 插件同级 node_modules/@yun520-1/heartflow
npm install -g @yun520-1/heartflow   # 最简方式
# 或指定本地开发副本
export HEARTFLOW_ENGINE_PATH=/path/to/heartflow/src/gate.js

⚙️ 配置

在 dsh 配置中：

{
  "plugins": {
    "@yun520-1/deepseek-heartflow": {
      "verbose": true,          // 日志输出
      "minAction": "rewrite",   // 自动监督最低等级: block | rewrite | verify
      "tolerateFailure": false, // 引擎缺失时是否 fail-closed（默认 true 拒绝放行）
      "maxTextChars": 4000      // 每次监督最大文本长度
    }
  }
}

🚀 使用示例

模型主动自检

模型在输出重要结论前调用：

heartflow_check("根据我们测试，这个方案是唯一正确的选择，所有其他方案都不行")

{
  "gate": { "action": "verify", "reason": "过度自信/绝对化声称" },
  "verdict": "需验证",
  "overallScore": 0.55,
  "findings": [
    { "dimension": "overconfidence", "severity": 0.7, "guidance": "避免绝对化表述，补充证据" }
  ]
}

深度审计

heartflow_analyze("这个产品一定会成功，因为市场分析显示需求巨大")

返回全维度打分 + 交叉分析 + 摘要。

快速裁决

heartflow_verdict("我没有证据，但我确定这是对的")

{ "action": "verify", "reason": "无证据支撑的确定性断言", "score": 0.6, "topFindings": [...] }

自动监督（无需显式调用）

配置 minAction: "verify" 后，模型每次工具调用入参都会被自动判别；block 级内容会被硬拦截并注入修正指令。
