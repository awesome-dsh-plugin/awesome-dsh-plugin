omdsh-dev/dsh-open-in-vscode

Stars ★ 39 Category Notifications & Integrations Added 2026-08-13

Open DSH workspace directories in VS Code directly from the web GUI.

Install

# from GitHub (first run asks for allowBuilds approval — follow the hint, retry)

dsh plugin --profile web add github:omdsh-dev/dsh-open-in-vscode

GitHub-sourced plugins run build scripts on your machine at install time. Only install sources you trust, and pin a commit (github:owner/repo#sha).
