Privacy

Last updated 2026-08-21. This page is written from the code, not from intent — every claim below is checkable in the repository that builds this site. If something here does not match what the site does, that is a bug and we want to hear about it.

The short version

This is a static site with no accounts and no server we operate. It counts page views without identifying you and stores nothing in your browser of its own. It is adding advertising — see below — and whether a cookie is ever set here depends on which network that turns out to be. Nothing else contacts a third party to render a page.

Analytics

We use Cloudflare Web Analytics. It is cookie-less, does not fingerprint you, and does not follow you across sites. It records page views and coarse technical facts — referrer, country, browser and device class — which Cloudflare aggregates. We see counts, never individuals, and there is no way for us to single you out from them. See Cloudflare Web Analytics.

Cookies and browser storage

This site sets no cookies of its own. If the Google AdSense placement described under Advertising is active, Google sets cookies for advertising; that is the only source of a cookie here. It writes nothing to localStorage or sessionStorage. Your filter and search state lives in the URL, which never leaves your browser unless you copy the link yourself.

What a page loads

Fonts and stylesheets are served from this domain — there are no third-party webfonts. There are no social widgets, no tag managers, and no scripts beyond the analytics counter named above, the small amount of filtering code in the page itself, and — when active — the ad script described under Advertising.

Images inside plugin pages

Each plugin page reproduces that project's README, which may contain images. A README is written by a third party, so an image in it would otherwise be a request your browser makes to a host we do not control — which is exactly how a tracking pixel gets into a page. We therefore restrict those images to GitHub's own hosting (raw.githubusercontent.com, user-images.githubusercontent.com, camo.githubusercontent.com, github.com) and drop the rest, keeping their alt text. Because this site is itself served by GitHub Pages, GitHub already receives the request for the page — so the images that remain introduce no party that was not already there.

Hosting

The site is served by GitHub Pages. Like any web server, GitHub receives your IP address in order to answer the request. See the GitHub Privacy Statement.

Links you choose to follow

Listings link to GitHub repositories, npm packages, and plugin authors' own sites. Following one is your decision, and from that point you are on someone else's site under their terms. We do not add tracking parameters to these links.

The catalog file

/plugins.json is published for anyone to read, including the dsh-market plugin and third-party tools. It describes plugins — names, descriptions, categories, install commands — and contains nothing about visitors to this site.

Contributing

Submissions arrive as pull requests on GitHub, under GitHub's terms and with the visibility any public repository has. Nothing is submitted through this website; it has no forms.

Advertising

An earlier version of this page said there were no ads and no arrangement to introduce any, and that if that changed this page would describe exactly what runs. That is what this section is.

This site is adding advertising. Two networks have been applied to, and at most one will ever run here — the first of them requires that it be the only ad on the page:

  • EthicalAds — a network for developer-focused sites. One ad per page, above the listing, never inside it. It sets no cookies and uses no local-storage identifiers, runs no advertiser code, hosts every ad asset on its own servers, and does no behavioural targeting: ads are chosen from the content of the page and a coarse location worked out from your IP at request time.
  • Google AdSense — this one does use cookies, which nothing else on this site does. Google and its partners set them to serve and measure ads and, where you have consented, to personalise them from your activity on other sites. Google receives your IP address as part of any ad request. Visitors in the EEA, the UK and Switzerland are asked for consent first and may refuse; refusing means non-personalised ads, not a broken page. You can review and change this at My Ad Center.

Both placements ship in the build script and stay inert until the matching publisher id is configured; the build refuses to run with both configured at once. While inert, no ad script is requested and nothing third-party loads. You can tell which state this site is in by viewing source and searching for ethicalads or adsbygoogle. /ads.txt lists who is authorised to sell ad space on this domain.

Ads never affect what is listed. Inclusion is decided by the criteria in contributing.md and has never been purchasable; that does not change because there is a banner on the page.
