# Awesome DSH Plugin [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

[English](README.md) | 中文

> [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（`dsh`）插件精选列表。

## 插件

- [dsh-vision-toolkit](https://github.com/Anionex/dsh-vision-toolkit) — 让纯文本模型更好地做视觉任务：带意图的图片问答、长截图 OCR、UI 还原等。
- [dsh-tianshu-tui](https://github.com/huiliyi37/dsh-tianshu-tui) — DeepSeek Harness 的终端 UI（TUI）。
- [dsh-at-file](https://github.com/omdsh-dev/dsh-at-file) — Codex 风格的 `@file` 文件引用，输入框里直接搜索并引用工作区文件。
- [dsh-open-in-vscode](https://github.com/omdsh-dev/dsh-open-in-vscode) — 一键在 VS Code 中打开 DSH 工作区目录。
- [dsh-notification](https://github.com/omdsh-dev/dsh-notification) — 桌面通知：回合完成等事件的系统级提醒。
- [dsh-custom-tool](https://github.com/omdsh-dev/dsh-custom-tool) — 创建和管理沙箱化的自定义 JavaScript 工具。
- [dsh_workflow](https://github.com/icetomoyo/dsh_workflow) — 把 UltraCode 式多 Agent 调度带给 DSH：可生成、可保存、可复用的工作流。
- [dsh-turn-rewind](https://github.com/Anionex/dsh-turn-rewind) — 对话回退：回滚会话与工作区到任意轮次。
- [dsh-visualize](https://github.com/Nagi-ovo/dsh-visualize) — 对话内生成式 UI：模型把交互式 HTML 卡片直接画进会话流。
- [dsh-share](https://github.com/hellodigua/dsh-share) — 一键分享你的 DSH 对话。

## 贡献

欢迎提 PR 收录你的插件：在 `README.md` 和 `README.zh.md` 中各加一行，格式 `- [名称](链接) — 一句话描述`。

也请为你的插件仓库添加 [`dsh-plugin`](https://github.com/topics/dsh-plugin) topic，方便大家发现。
