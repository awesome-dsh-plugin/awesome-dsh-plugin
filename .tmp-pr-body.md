**What it is.** `dsh-boot-nexus` merges two boot plugins into one overlay: the intro video from `dsh-boot-animation`, the six-act cold start from `dsh-boot-suite`, and a screensaver, chosen per launch. One root node, one state machine, one clock, one config file; every option lives in a single settings card (intro / suite / screensaver / media pool / advanced).

**Self-contained.** The suite engine, templates, voices and sound effects are vendored into `assets/suite`, so the plugin keeps playing after the original plugins are uninstalled. The old plugins' rows are disabled rather than required. The entry says not to enable it alongside `dsh-boot-suite` / `dsh-boot-animation`, because all three claim the same boot layer — this is the conflict the merge exists to remove.

**Installable without a build.** `tarball:` points at the v0.5.2 release asset (57.8 MB, no build step); `icon:` is a 256×256 PNG hosted in the repo. 60 unit tests ship in `test/`, and the repository is MIT.

**Credits.** The engines and media come from [lxj5820/dsh-boot-animation](https://github.com/lxj5820/dsh-boot-animation) and [LeeRolling/dsh-boot-suite](https://github.com/LeeRolling/dsh-boot-suite); both are credited at the top and bottom of the README, and the entry does not claim their work as new. `LeeRolling/dsh-boot-suite` already has its own entry on the list — this one is the merged, self-contained variant, which is why it is listed separately rather than as a duplicate.
